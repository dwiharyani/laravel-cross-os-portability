**Laravel Cross-OS Portability — Evidence Atlas**

Explore our interactive research dashboard presenting the
experimental methodology, dataset characteristics, statistical
analyses, portability issues, and LLM-assisted findings.

### What Can You Explore?

- **Research Methodology:** Interactive study workflow,
  repository selection, and experimental design.
- **Dataset and Sampling:** GitHub crawling, eligibility criteria,
  repository popularity, stars, forks, and containerization.
- **Cross-OS Results:** PASS, FAIL, NOT_RUN, and INTERRUPTED
  outcomes across three operating systems.
- **Statistical Analysis:** Matched comparisons, effect sizes,
  statistical significance, and verdict agreement.
- **Portability Issues:** PHP extensions, dependencies,
  filesystem behavior, test harnesses, and environmental barriers.
- **LLM-Assisted Analysis:** Investigated cases, reported local
  fixes, architectural constraints, and validation limitations.
- **Repository Explorer:** Search and inspect the execution
  results of all 921 repositories.
